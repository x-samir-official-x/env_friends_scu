## Core anti-generic rules (from design-taste-frontend README + references)
- INVENTORY FIRST: list client's name/meaning/street/numbers/constraint/materials/hours — never guess.
- NO DEFAULT TEMPLATES: ban 6-line text wraps, generic card grids, gradient-boxes, placeholder divs, "AI-made" typography loops.
- REAL PHOTOGRAPHY ONLY: Unsplash open-collection images, never stock placeholders; hero must be image-led, not text-heavy.
- TYPOGRAPHY RULES: real free fonts (Cairo + Inter already set); no system-default sans; strict leading/tracking; optical sizing awareness.
- PALETTE CALIBRATION: 80/15/5 rule enforced (navy 80%, slate 15%, gold/emerald 5%); no rainbow gradients.
- ASYMMETRIC LAYOUTS: no perfect 2-col mirrors; hero visual left / text right (already done); section headers off-center.
- MICRO-MOTION: reveal on scroll via IntersectionObserver (done); count-up stats; no jarring instant jumps.
- NO EMOJIS / No FontAwesome / No generic icons — Phosphor only (done).
