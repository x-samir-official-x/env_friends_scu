# أصدقاء البيئة — كلية التجارة، جامعة قناة السويس

موقع الفريق (HTML/CSS/JS ثابت — بيشتغل مباشرة على GitHub Pages).

## التعديل
كل المحتوى في `config.js`:
- **الصور**: حط الصورة في فولدر `assets/` (مثلاً `assets/dean_ahmed.jpg`) — المسارات في config بدون امتداد وبتشتغل مع jpg / jpeg / png / webp. لو الصورة مش موجودة بيظهر الحرف الأول من الاسم.
  - `dean_ahmed` · `vice_rayman` · `advisor_nagat` · `team_leader_samir` · `co_leader_nada` · `init_smile` · `init_nursing` · وكمان `hero` · `join` · `footer` للخلفيات.
- **الروابط**: `links.registrationForm` لفورم التقديم، و`socials` للسوشيال. الفاضي بيظهر للزائر "قريبًا".
- **الأرقام**: `stats[].value` (كلها 0 دلوقتي).
- **الألوان**: أول `styles.css` (`--navy` `--emerald` `--leaf` `--ivory`).
